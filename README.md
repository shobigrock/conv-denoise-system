## 内容
* 教師あり学習+交差検証による信頼度推定、除去
    * ラベルのノイズ除去フレームワーク
    * そのあと、後々使用する機械学習モデルに学習させて予測精度を見る
* DenoiseSSL (教師なし学習 + 半教師あり学習)
    * 予測精度を改善するフレームワーク
    * Xでクラスタリングを行う
    * 各クラスターで多数決を行い、ラベルの代表値を決める
        * 多数決だとマジョリティに支配されて1が教師なしになるだけだから意味ない
        * 多数決でなく、事前分布(5, 95)のβ分布を仮定->事後分布を推定、事後分布の信頼区間を外れるデータを教師なしとすればいい？
    * 代表値でないラベルをラベル無しとみなして、半教師あり学習を行う
