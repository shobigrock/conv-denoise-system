# conv-denoise-system
CVデータにε-label-DPを満たすノイズ付与(Randomized Response Mechanism) が行われた場合に、教師あり学習+層化k分割交差検証を用いてノイズ除去を行うフレームワークです。

## 概要
本フレームワークは、以下の流れでラベルのノイズ除去を行います。
* （真ラベルにε-label-DPを満たすノイズ付与を行い、ノイズラベルとする）
* 特徴量とノイズラベルを用いて、層化k分割交差検証を行い、各ノイズラベルに対して教師あり学習の予測値を割り当てる
* ノイズラベルと予測値の差分の絶対値を、ラベルの不確実性とみなす
* 不確実性が閾値を上回るようなラベルをノイズありラベルとみなし、ラベルの値を反転させる
* （一部反転させたラベルとノイズラベルをそれぞれ真のラベルと比較し、一部反転ラベルがノイズラベルより真のラベルに近いことを確かめる）

## データについて
scikit-learnのmake_classification関数により人工データを作成しました。実験では、引数のn_informativeを3~8に変更しながら実験を行いました。（仮説：n_informativeが多いほど学習しやすい -> ノイズ除去精度が高まる）

## モデルについて
教師あり学習モデルにはLightGBMを用いていますが、データの特性により学習のより進むモデルに変更することが望ましいです。

## 使い方
main_cross_valid.pyをターミナルから実行すると実験結果データが得られます。その後make_fig.pyを実行することで、実験結果の図を得ることが出来ます。

## 実験結果
figフォルダ配下に実験結果グラフが格納され(てい)ます。kは交差検証のFold数、seedは乱数シード値、infoはn_informativeの数、epsはノイズのプライバシー保護水準を表しています。
